Ключевые возможности

Универсальные решения для всей экосистемы GTA San Andreas и современных лаунчеров

DXVK Vulkan Революция

Трансляция устаревших инструкций Direct3D 9 в современный низкоуровневый Vulkan API. Избавляет от микрофризов, разрывов кадров и равномерно распределяет нагрузку на GPU в GTA SA, SA-MP и CRMP.

v1.10.3 v2.3 v3.0 v3.1.1 Async

Патч 4 ГБ памяти (LAA)

Снимает стандартный лимит 2048 МБ 32-битного движка GTA SA. Игра получает доступ к полным 4 ГБ виртуального адресного пространства для HD-текстур, кастомного транспорта и ресурсоёмких модификаций.

motion.exe samp.exe gta_sa.exe Anti-Crash

Первая адаптация: Motion Project

Motion стал первым лаунчером с бесшовной поддержкой «из коробки»: автоматический обход сброса файлов при обновлениях, синхронизация сетевого API и фоновая служба в трее.

Daemon Port 49742 Tray Icon Motion Ready

Самодиагностика и отчёты

Встроенный генератор HTML-отчёта диагностирует поддержку Vulkan драйвером вашей видеокарты, статус LAA-флагов, целостность dll-библиотек и формирует готовый лог для решения проблем.

Системные требования и рекомендации

Подберите оптимальную версию DXVK для вашей видеокарты

Recommended

DXVK 3.1.1 / 3.0

Для современных видеокарт (NVIDIA GTX 10xx+, RTX, AMD RX 5000/6000/7000, Intel Arc). Максимальный FPS, асинхронные шейдеры, Vulkan 1.3+.

High Compatibility

DXVK 2.3

Идеальный баланс совместимости и стабильности. Подходит для NVIDIA GTX 9xx/7xx и AMD RX 4xx/5xx.

Legacy GPUs

DXVK 1.10.3

Для старых видеокарт и встроенной графики (Vulkan 1.1). Минимальные системные требования.
